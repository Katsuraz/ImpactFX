# ImpactFX · Fabric Minecraft 26.3

**Version:** 0.1.0-alpha.1 (source checkpoint; Minecraft runtime and compiled JAR unverified)

ImpactFX is a client-side cinematic impact effects mod for explosions and mace smash attacks. Its current implementation provides lightweight directional HUD overlays, six visual presets, intensity scaling, and configurable accessibility options. Advanced world-aware scene shaders and true monochrome rendering remain future work.

Build with JDK 25 and Gradle 9.7.1 using `gradle build verifyLogic` after the source project is uploaded. A GitHub Actions workflow is included to package build artifacts. No playable JAR has been verified.

See the source project and project files for detailed implementation and planned features.
